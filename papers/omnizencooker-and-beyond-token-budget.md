## III. Mechachleopteryx (Nate): *Research Beyond the Token Budget: External Verification, Composable Toolchains, and the Cost of Agent Loops*

**Companion Repository:** [`https://github.com/standardgalactic/unscannable-interfaces`](https://github.com/standardgalactic/unscannable-interfaces)

### 1. Abstract & Thesis
Language-model agents are increasingly billed per token and evaluated on long-horizon coding and research benchmarks. When every intermediate hypothesis, failed proof attempt, or redundant file scan passes through the context window, token spend grows superlinearly with loop depth while reliability degrades.

By moving verification, state reduction, and structural indexing out of the autoregressive loop into **deterministic external verifiers and composable Unix/MCP toolchains**, total loop cost drops while soundness increases.

### 2. The Agent Loop Cost Model
For an agent executing $J$ steps where step $j$ has raw action/generation token cost $a_j$, context-reuse / cache-hit rate $r_j \in [0, 1]$, and external tool/verification overhead $s_j$:

$$C = \sum_{j=1}^{J} \Big[(1 - r_j)\,a_j + s_j\Big]$$

- **Unverified Autoregressive Loop ($r_j \to 0$, large $J$):** The model re-reads unscannable interfaces, hallucinates intermediate state, and pays full uncached token cost $(1 - r_j)a_j$ across retry cascades.
- **Externally Verified Composable Loop ($r_j \to 1$, small $J$, deterministic $s_j$):**
  1. **Scannable Interfaces (`standardgalactic/unscannable-interfaces` + `8b-is/smart-tree`):** Compact, deterministic structural views replace noisy multi-thousand-line dumps, driving $a_j$ down by $60\text{--}95\%$ and keeping prefix cache reuse $r_j$ high.
  2. **External Verification (`spherepop-kernel` / `upz` / Go-to-Python cross-checkers):** Instead of asking an LLM whether a rewrite system is confluent or a schedule is race-free, an external verifier checks `66,999,800` diamond-property pairs in milliseconds ($s_j \ll a_j$) and returns a 1-line counterexample or `0 disagreements` certificate.

- Under Condorcet's jury theorem (1785) and Dietterich (2000), majority voting over $M$ exchangeable classifiers with independent error $\varepsilon < 1/2$ drives ensemble error down exponentially in $M$, whereas shared failure modes bounded by pairwise correlation $\rho$ create a floor $\rho \cdot \text{Var}$ that no $M$ can cross.
- **The Safety-Aligned Refusal Paradox (`0.98` Refusal Rate, Soft Max `~11` Votes):**
  - On general tasks without safety-triggered topics (`finance`, `law`, `health`, or adjacent borderline domains), scaling ensemble voters improves accuracy monotonically.

## VIII. `AURSNAP1` 1,000,000-Node Single-Register Binary Search Benchmark (`120.0 MB` Working Set)

**Implementation:** [`alexiai/rust/gaia-mlx-quant/examples/bench_aursnap_1m.rs`](https://github.com/8b-is/alexiai/blob/main/rust/gaia-mlx-quant/examples/bench_aursnap_1m.rs) & [`AurSnapIndexView`](https://github.com/8b-is/alexiai/blob/main/rust/gaia-mlx-quant/src/wupz.rs)

- **Snapshot Geometry ($N = 1,000,000$ nodes):**
  - **Index Table:** $1,000,000 \times 32\text{ B} = 32.0\text{ MB}$
  - **String & Payload Arena (`24B` key + `64B` payload):** $1,000,000 \times 88\text{ B} = 88.0\text{ MB}$
  - **Total Mapped Snapshot:** $\approx 120.0\text{ MB}$ (exceeding L2/L3 cache capacity)
- **Cache-Line Mechanics Across $\lceil \log_2(1,000,000) \rceil = 20$ Binary Search Probes:**
  - **Standard Arena-Pointer Binary Search (`get_by_id_arena_only`):** Every probe reads the 32-byte index entry *and* dereferences `arena[id_off..id_off + id_len]` across the $88.0\text{ MB}$ String Arena, incurring up to **40 random cache-line touches** ($20$ index + $20$ arena) per lookup.
  - **Inlined 8-Byte Big-Endian `key_prefix: u64` (`get_by_id`):** Compares `entry_prefix.cmp(&target_prefix)` in a single CPU register instruction with **zero String Arena reads** during all 20 narrowing steps (touching the String Arena only once at the final matched index to verify the full slice and payload).
